Barry’s Vinyl Vault 3.6 — Signed & Collectible Records + Multiple Currencies

Upload the contents of this folder into a NEW GitHub folder named Barrys_Vinyl_Vault_3_6_COLLECTIBLES_CURRENCY. Do not replace Version 3.5.

Backup JSON from 3.5 before testing. Sign in to cloud and download the cloud collection before making changes. Verify record count.

New fields: autograph authentication, provenance, certificate reference, valuation source/date, insurance amount/currency, purchase and market value currencies. Existing numeric purchase and value fields default to CAD.

Display currency is a browser-specific setting. Exchange rates can be refreshed from open.er-api.com (internet required), or manually entered. Saved rates can become stale; the app displays their date and source. No invented conversion rates. Original amounts and currencies are preserved in the records.

No actual appraisal or authentication is provided. Do not treat estimated values as verified market prices.
