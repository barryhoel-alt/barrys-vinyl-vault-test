Secure cloud sync (optional)

To sync Windows and Android, first create a Supabase project and run the SQL in SETUP-CLOUD-SYNC.txt. Never enter a service-role key here. Your project URL and publishable/anon key are public identifiers, not secrets.

First-time setup: sign in on Windows and upload the verified collection. Then sign in on Android and download it. Afterward, changes sync automatically while online. If both devices change the same collection before syncing, syncing pauses for your review instead of silently overwriting data.
