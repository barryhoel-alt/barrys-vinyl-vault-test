BARRY’S VINYL VAULT 2.2

Includes the existing 2.1 album cover and MusicBrainz track lookup, CAD purchase/value fields and valuation summary, per-record listening sessions, and OPTIONAL Supabase cloud sync.

To upgrade: Export Backup JSON from your current live 2.1 site first. Extract this ZIP and deploy the ENTIRE Barrys_Vinyl_Vault_2_2 folder to your EXISTING Netlify project. Use the same website address to preserve browser-local records. After deploying, hard-refresh Windows and restart Android app. Verify your data before making changes.

Cloud sync is NOT configured automatically. Read SETUP-CLOUD-SYNC.txt. Do not upload your Supabase password or secret keys.

Market value fields are your own CAD estimates, NOT automatically researched prices. Listening history is stored in each album record and included in JSON backups.
